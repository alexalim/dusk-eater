### QA-1 WebGL 실패 안내가 가려짐
- 원인: `#no3d` 안내가 DOM에서 `#title`보다 앞에 있고, 화면 전환(`show`)이 안내를 관리하지 않음
- 수정: 렌더러 생성에 실패하면 `show('no3d')`만 호출하고 타이틀을 띄우지 않음
- test_definition (E2E): WebGL을 끈 Chromium(`--disable-webgl`)으로 열었을 때 `#no3d`는 보이고 `#title`과 `#hud`는 숨겨져 있어야 한다.

### QA-2 경비원을 먹을 수 없음
- 원인: `inCone`은 원뿔 꼭짓점(거리 < 1)을 안쪽으로 판정하므로, 경비원은 항상 자기 불빛 속에 있었음
- 수정: 먹기 판정과 힌트에서 `inBeam(x, y, exclude)`로 자기 불빛을 제외
- test_definition (시뮬레이션): 탐욕형 봇으로 마을을 5판 돌렸을 때 경비원을 1명 이상 먹은 판이 있어야 한다. (수정 전 0/5판, 수정 후 4/5판)

### QA-3 밤 진입 시 셰이더 재컴파일
- 원인: `sunLight.castShadow`를 밤에 false로 바꾸면 그림자를 쓰는 모든 재질이 다시 컴파일됨
- 수정: castShadow는 그대로 켜 두고 `intensity = 0`만 설정
- test_definition (E2E S11): 101초와 103초 시점의 `renderer.info.programs.length`가 같아야 한다. (수정 전 7→10, 수정 후 7→7)

### QA-4 조명 포화와 아침 대비
- 수정: `hemi + sun·sin(고도) = 1`이 되도록 햇빛 세기를 자동 보정(상한 1.8)
- test_definition (E2E S9): 모든 시간대에서 햇빛 받는 바닥의 중앙 밝기 < 245, 햇빛/그림자 밝기 비 ≥ 2.0이어야 한다. (수정 후 밝기 163~220 / 그림자 65~81)

### QA-5 햇빛 속에서 시작
- 1차 수정(도로 교차점 중 0초에 그림자 속인 곳)은 표본을 30판으로 늘리자 1/12 → 13/30으로 오히려 나빠졌음. 경비원이 첫 프레임에 손전등 방향을 바꾸고, 조건을 만족하는 교차점이 없으면 햇빛 속 중앙으로 시작 위치가 넘어갔기 때문
- 최종 수정: 건물 밖 20 간격 격자 전체에서, 경계로부터 20 이상 안쪽 그림자이고 모든 불빛 반경 + 30 밖인 지점 중 중앙에 가장 가까운 곳
- test_definition (E2E S10): 스테이지별로 15판씩 시작했을 때 시작 프레임의 `player.lit`이 모두 false이고 대체 위치 사용 횟수가 0이어야 한다. (최종 0/30, 대체 위치 0)

### QA-9 벽 밑동 빛 샘 (peter-panning)
- 원인: 그림자 깊이 보정값 `bias -0.0006`(약 4 월드 단위)과 `normalBias 0.6`이 해가 낮을 때 그림자를 벽에서 떨어뜨림
- 수정: `bias -0.0001`, `normalBias 0.15`. 바닥은 그림자를 드리우지 않으므로 바닥에는 줄무늬(acne)가 생길 수 없고, 지붕도 스크린샷으로 확인함
- test_definition (E2E S9): 손전등 영역과 가림 경계를 뺀 바닥 표본에서 판정과 픽셀 밝기의 일치율이 시간대마다 97% 이상이어야 한다. (수정 전 항구 저녁 92.0%, 수정 후 99.1%)

### QA-10 지도 화면 레이아웃
- 원인: 지도 배경용 CSS `#map svg`가 노드 아이콘 SVG에도 적용됨, 지도 너비가 화면 높이를 고려하지 않음
- 수정: 선택자를 `#map > svg`로 한정, 지도 너비를 `clamp(180px, (100dvh − 380px) / 1.5, min(100%, 380px))`로 설정
- test_definition (E2E): 375×667에서 `#btn-go`의 아래쪽이 화면 높이 이하이고, 노드 아이콘 너비가 원(58px)보다 작아야 한다. (수정 후 614/667px, 30/58px)

### QA-6 가로 화면 버튼 잘림
- 수정: `.overlay`에 `overflow-y: auto`, `justify-content: safe center`
- test_definition (E2E S8): 844×390에서 `#btn-select`를 스크롤해 보이게 한 뒤 화면 안(±1px)에 있어야 한다.

### QA-7 세로 고정 (설정됨, 기기 확인 대기)
- 수정: `ios/App/App/Info.plist`의 `UISupportedInterfaceOrientations`를 세로 하나만 남기고 iPad용 항목을 삭제했습니다. `TARGETED_DEVICE_FAMILY`는 iPhone 전용(1)으로 바꿨습니다. iPad까지 지원하는 앱이 세로만 허용하면 App Store 심사에서 거절되기 때문입니다.
- test_definition (수동/E2E): iOS 빌드를 가로로 돌렸을 때 화면이 회전하지 않아야 한다.

### QA-8 실기기 성능 (열림)
- 이 환경에서 측정한 값: 그리기 호출 164~210회/프레임, 삼각형 8만~16만 개, 렌더링을 뺀 JS 처리 시간 p95 0.7ms 이하
- 할 일: iPhone에서 후반부(크기 최대, 밤)에 프레임 속도를 측정. 부족하면 그림자 맵 해상도를 2048에서 1024로 낮추고 픽셀 배율 상한을 2에서 1.5로 낮춤
- test_definition (수동): iPhone 실기기에서 마을·항구 후반 30초 동안 평균 50fps 이상이어야 한다.
